# Orbit

Laptop-first floating desk. Each task has a title, a custom step list, and a checkbox that advances one step at a time. Autosaves in the browser (`orbit-desk-v1`). No login, no server database.

## Shortcuts

Ctrl/Cmd 1–9. See in-app Shortcuts widget.

## Deploy

Vercel build: `node scripts/with-app-env.mjs vite build`
